## Interaction matrix

- Native scroll controls one normalized, damped scene timeline.
- Forward and backward scrolling use the same camera/target paths.
- Pointer movement adds bounded camera influence; the sculpture can be hovered/clicked to pause its ambient rotation.
- Discover, Contact and marketplace entry are real navigation/actions.
- Skip intro takes visitors to the existing homepage. Direct application/deep links bypass the intro.
- Replay clears the device-session entry preference and returns to the opening.
- Optional sound synthesizes an original ambient tone only after a user action; it is not reference audio.
- Reduced-motion and WebGL failure expose the existing marketplace immediately.
