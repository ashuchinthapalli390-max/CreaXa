# Portrait integration notes

1. Run `python scripts/download_licensed_photos.py` on a network-connected developer machine (Pillow required).
2. Inspect actual portraits, confirm artist identity and file integrity; do not blindly deploy based on filename.
3. Serve downloaded CC-licensed portraits locally after recording proper attribution, license, link and modifications.
4. If photo has no reuse authorization, leave it out. Use the truthful SVG initials fallback.
5. External artists remain editorial references, not registered members or endorsements.
6. Do not crop/recolor CC BY-SA portraits without ensuring applicable derivative licensing requirements.
7. Do not treat a video thumbnail from a third-party site as a reusable image unless explicitly licensed or authorized.
